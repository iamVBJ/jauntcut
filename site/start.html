Get started

Install Jauntcut and make your first reel.

Jauntcut runs from Terminal today: you put footage in a folder, describe the edit in a small file, and render. Installing takes a few minutes, longer on a Mac that doesn't have Apple's developer tools yet. A Mac app that needs no Terminal is next on the roadmap.

Requirements

  • macOS 14 (Sonoma) or newer. Subject cutouts use a Vision feature that arrived in macOS 14.
  • Apple silicon recommended. Intel Macs work, but the vision steps are much slower.
  • About 2 GB of free space for Jauntcut and its renderer, plus room for your footage.
  • Homebrew (brew.sh), used to install Node and ffmpeg if you don't have them.

The installer sets up everything else: Apple's command-line tools, Node 20 or newer, ffmpeg, and Python's NumPy and Pillow.

Install

Open Terminal (in Applications → Utilities), paste this and press Return:

curl -fsSL https://raw.githubusercontent.com/iamVBJ/jauntcut/main/install.sh | bash

It installs into ~/jauntcut. In order, it:

  1. Checks your Mac and Apple's command-line tools. If those are missing, macOS shows an install window; let it finish, then run the command again.
  2. Installs Node and ffmpeg with Homebrew if they are missing (it asks first), and NumPy and Pillow for Python.
  3. Downloads Jauntcut and its packages.
  4. Downloads the depth model (Apple's Core ML build of Depth Anything V2 Small, 48 MB) and checks every file against its published checksum.
  5. Runs a self-check: the code compiles, a Vision tool builds, Python's modules import.

It never uses sudo, and running it again updates an existing install.

Options

Add options after bash -s --, for example:

curl -fsSL https://raw.githubusercontent.com/iamVBJ/jauntcut/main/install.sh | bash -s -- --check
OptionWhat it does
--checkOnly reports what is installed and what is missing. Changes nothing.
--dir <path>Install somewhere other than ~/jauntcut.
--no-depthSkip the 48 MB depth model. You only need it for 3D moves on photos.
--yesInstall missing tools without asking.

Prefer to read it first?

curl -fsSL -o install.sh https://raw.githubusercontent.com/iamVBJ/jauntcut/main/install.sh
open -e install.sh        # read it in TextEdit
bash install.sh

Your first reel

  1. Create a reel 
    cd ~/jauntcut
npm run new night-market

    This makes topics/night-market/ with an empty edit file and two folders.

  2. Add footage and a song

    Put photos and videos in topics/night-market/raw/ and one song in topics/night-market/music/. Straight from your phone is ideal: vertical, at least 1080×1920.

  3. Prepare the media 
    npm run media night-market

    Converts every file to an edit-ready format and finds the song's beat.

  4. Write the edit

    Open topics/night-market/reel.ts and list your clips. Lengths are in beats of the song:

    clips: [
  { src: "IMG_0412.MOV", beats: 6 },
  { src: "IMG_0415.HEIC", beats: 4, motion: "push-in" },
  { src: "IMG_0420.MOV", beats: 8, startAt: 2.5, transition: "dissolve" },
],
  5. Preview 
    npm run studio

    Opens the reel in your browser. It updates as you save the file.

  6. Render 
    npm run render night-market

    Runs every check, then renders out/night-market.mp4 and an upload-ready copy in out/instagram/. If a check fails, it names the clip and what to change; nothing renders until it passes.

Every option a clip can take (speed ramps, slow motion, 15 transitions, 11 title styles, depth moves, text set into the scene) is listed in the editing reference.

What a reel must pass

The checks are strict on purpose: they catch what makes viewers scroll away. These are the ones a first reel usually meets (limits for the default calm style; energetic is tighter):

RuleLimitIf it fails
Length20 to 45 secondsAdd or remove beats.
No upscalingFootage is never enlarged past its own pixelsUse footage of at least 1080×1920. A push-in or pan needs a little more room, which phone photos (3024×4032) have.
OpeningThe first clip runs at most 1 s past the opening textShorten the first clip.
Photos mid-reelAt most 2 s, and they must moveGive the photo a motion, or fewer beats.
HoldsStill shots 1.6 s, gentle 3 s, moving 4 sTrim the shot, or pick a livelier moment with startAt.
ClosingThe last clip at most 4.6 sShorten the last clip.
TextAt most 17 characters a secondShorten the line.

Commands

CommandWhat it does
npm run new <name>Creates a reel folder from the template
npm run sortSorts everything in inbox/ into reels by GPS and time
npm run review <name>Frame strips, blur and shake, activity and burned-in text, to pick moments
npm run media <name>Converts media and analyses the beat
npm run studioLive preview in the browser
npm run checkRuns the pre-render checks only
npm run render <name>Checks, renders, and makes the Instagram copy
npm run song -- search "<title>"Finds a song to cut a guide copy of an Instagram sound

Update or remove

Update: run the install command again. It pulls the latest version and leaves your reels alone (they live in topics/, which updates never touch).

Remove: delete the folder. Your own reels are inside it, so move any you want to keep first.

rm -rf ~/jauntcut

Node, ffmpeg, NumPy and Pillow stay installed for other apps. Remove them with brew uninstall node ffmpeg if nothing else needs them.

Troubleshooting

"A window asks to install the command line developer tools"

Click Install and wait for it to finish (it can take several minutes), then run the install command again.

"Homebrew not found"

Install it from brew.sh, open a new Terminal window, then run the install command again.

"would upscale"

The footage is smaller than the frame needs. Use the original file from your phone rather than a downloaded or messaged copy, or remove the motion or zoom on that clip.

Not sure what is missing?

Run the installer with --check. It lists every requirement and changes nothing. Still stuck? Open an issue with its output.
